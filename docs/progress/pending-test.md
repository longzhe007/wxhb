# 待测试

## Muse Video 参考音频与视频

- `muse-video` 现在会把本地音频、视频和图片参考转换为 Muse2API 可接受的 Data URL，并分别发送到 `audios`、`videos` 和 `images`。
- 验证方式：在画布中为 Muse 视频节点连接一段本地音频，提交生成后确认不再出现“TokenDance 本地视频和音频参考必须先取得公网地址”，并确认成片受音频节奏或内容影响。
- 验证限制：单个本地参考素材不能超过 40 MiB，图片、视频和音频参考合计最多 10 个。
